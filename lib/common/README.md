# Common Components

This directory contains reusable components that are used across the application.

## Structure

- `widgets/`: Reusable UI components
- `utils/`: Reusable utility functions and helpers
- `animations/`: Reusable animation controllers and effects
- `mixins/`: Reusable Flutter mixins for state management

## Usage Guidelines

1. Components in this directory should be truly reusable across multiple screens
2. Each component should have a single responsibility
3. Components should be well-documented with clear usage examples
4. Avoid tight coupling with specific features
